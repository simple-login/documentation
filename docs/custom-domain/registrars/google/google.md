# Manage a migrated domain

[Google Domains completed the migration of all domains to Squarespace](https://domains.google/intl/en/) on July 10, 2024.
To configure a migrated domain, follow [Squarespace's instructions for editing domain records](https://support.squarespace.com/hc/en-us/articles/360002101888-Edit-your-domain-s-DNS-records) and use the record values on the [SimpleLogin domain page](https://app.simplelogin.io/dashboard/custom_domain).

For an overview of the setup, see [Add a Custom Domain](/docs/custom-domain/add-domain/).
